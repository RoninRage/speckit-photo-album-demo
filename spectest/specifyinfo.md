Create the Photo Album application with these features:

User Stories:
1. Users can create new albums with a name
2. Users can view a list of all albums with creation date
3. Users can open an album to see its photos in a grid/tile layout
4. Users can upload photo files (JPEG, PNG, WebP) to an album
5. Users can see a preview thumbnail of each photo
6. Users can drag and drop photos between albums to move them
7. Users can reorder photos within an album by dragging
8. Users can delete photos with a confirmation dialog
9. Users can delete albums (only if empty)
10. All data persists between browser sessions
11. UI is responsive on mobile, tablet, and desktop
12. Album and photo counts are displayed
13. No server or authentication required

Constraints:
- No photos are actually uploaded anywhere
- All data stored locally in the browser
- No external API calls
